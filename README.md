# Cross-Scale Causal Formalization

Research initiated from **Nolan Downard's hypothesis** about learning structural constraints from partial, context-dependent “shadows” of hidden systems.

**Central question:** Under what assumptions can multiple partial observations identify a property, predictive abstraction, or causal constraint of an evolving hidden system?
