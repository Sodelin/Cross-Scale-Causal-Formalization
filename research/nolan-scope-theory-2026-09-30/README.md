## Status and provenance

These are conceptual analyses, elementary hand arguments and historical research records. No new Lean build, empirical validation, measured search speedup or universal self-similarity theorem is claimed. NANUQ verification/publication statements retain their original recorded scope and dates.

The [source manifest](SOURCE-MANIFEST.json) pins imported commits and blobs. Relative Markdown links in imported reports were made absolute to their original source commits so supporting evidence remains reachable. Other agents can cite this package without reconstructing the chat. Earlier unavailable responses are not invented; this is a consolidation of the available work, not a claim to recover every conversation.

## A useful next question

For one explicit model class, outcome and permitted observations, determine which remaining models disagree about the outcome; generate a probe or representation that separates that disagreement; and show whether the result opens a more consequential target. This connects observation-based inference to target generation while avoiding a new foundation-only project.
