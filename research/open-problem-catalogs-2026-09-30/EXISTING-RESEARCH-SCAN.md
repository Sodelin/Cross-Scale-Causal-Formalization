# Existing research scan for the bio–psycho–social omnibus

Recorded 30 September 2026 UTC. This scan recovers already sourced questions and reusable mathematics before the omnibus spends compute constructing new foundations. It reads 18 selected public entrypoint documents in four repositories, at immutable commits listed below. It is not a claim that every source file, repository, issue, branch or paper has been read, and it does not independently rerun Lean or establish current literature-wide novelty. The category catalogs perform the fresh primary-source and current-status checks.

**Finding:** there are already genuine author-proposed biological extensions and source-stated social questions in the corpus. Most existing proofs are completed model consequences, known mathematics or infrastructure. These are useful dependencies; they must not be counted as new solutions to those external questions. The strongest reusable cross-domain asset is the distinction between an observation, its compatible hidden models, and the particular response to be recovered.

## 3. Reusable modules for a distributed omnibus

The omnibus can link modules without re-proving known foundations or pretending that analogy is a theorem:

1. **Observation contracts:** define hidden state or history, retained evidence, admissible-model class and target response separately. Reuse observation-fibre decoder criteria and explicit collision witnesses. For uncertain data, define compatibility statistically rather than use noiseless exact fitting.
2. **Controlled preservation:** reuse all-word commutation and stochastic joint-law interfaces where their hypotheses match. A biological-to-psychological or individual-to-group link must state the map, allowed controls, retained responses and lost information.
3. **Measurement and identification:** use elementary probe and additive-bias results as infrastructure, with the actual measurement model supplied externally. Stronger evidence can shrink compatible models without identifying a mechanism.
4. **Dependence controls:** reuse the independent-versus-repeated block contrast as a warning against treating extra observations as extra independent information. A new application still needs its own sampling law.
5. **Lineage and graph modules:** reuse ARG restriction, ownership, exact edge images and ancestry-path contracts. Exact edge preservation does not imply path reflection; the ownership packet has a concrete two-edge counterexample.
6. **Contribution provenance:** preserve source-proposed problems, internally formulated subtargets, already solved source questions, verified established mathematics and candidate new deductions as different records.

The most useful default is a small problem packet containing an external question, closest theorem, model-to-source map, consequential target, dependency references, and proof or experiment criterion. An agent that lacks execution tools can contribute source interpretation, a mathematical attack or an alternative target through that same packet; tool access is not an intelligence or credit ranking.

## 4. Internal milestones that must not masquerade as external open problems

Already listed project directions include extinction-aware pedigree IAP classification, noisy/corrupted probe selection, multi-indicator measurement anchors, budgeted tasks with outside options, aggregate comparison under common weights, biologically restricted ownership recovery and approximate stochastic abstraction. They can be meaningful research tasks, but a current primary-source problem match and closest-result comparison are still necessary before a discovery claim.

In particular:
- A new exact transition matrix is not by itself a new result: Planidin's supplement already contains spectral mathematics for a constant linear life cycle.
- Formalizing a known theorem is a verification contribution, not closure of a scientific open question.
- A generic uncertainty or non-identification lemma does not answer a named latent-construct question until the actual model classes and observation law are matched.
- An all-level reduction in phylogenetic networks demonstrates a successful proof mechanism. It does not establish that every cross-scale problem admits a bounded-obstruction reduction.
